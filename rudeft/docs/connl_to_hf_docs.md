# Connl to HF

Cкрипт `src/translator_connl_to_hf.py` обрабатывает файлы в формате CoNLL из заданной директории и конвертирует их в формат **Hugging Face Dataset** и добавляет для каждого элемента свой id. Дополнительно, при наличии соответствующих данных, он добавляет русский перевод к английским текстам.

## Запуск скрипта

Скрипт можно запустить из командной строки, передавая следующие аргументы:

1. **--deft_corpus_folder** (опционально):  
* Указывает путь к папке с файлами CoNLL с расширением .deft.  
* Дефолтное значение:deft_corpus/data/deft_files

	`python src/translator_connl_to_hf.py --deft_corpus_folder "path/to/your/files"`

2. **--output_file** (опционально):  
* Имя файла, в который будут сохранены обработанные данные в формате JSON.  
* Дефолтное значение:deft_corpus.json

	`python src/translator_connl_to_hf.py --output_file "output_data.json"`

3. **--ru_folder** (опционально):  
* Указывает путь к папке с русскими текстами для сопоставления.  
* Если аргумент не передан, русский текст добавляться не будет.  
* За сопоставление русских и английских текстов отвечает файл src/eng_ru_matching_pipeline.py

	`python src/translator_connl_to_hf.py --ru_folder "path/to/russian_texts"`

Скрипт можно запустить из командной строки, передавая следующие аргументы:  
`python src/translator_connl_to_hf.py --deft_corpus_folder "data/my_deft_data" --output_file "processed_data.json" --ru_folder "russian_texts"`

## Формат русских текстов

Требования к русским текстам:

* Каждая строка должна начинаться с номера предложения (например, `2.` или `38.`).  
* Номер предложения может быть в кавычках или без них (например, `«2.` или `2.`).  
* После предложения идет метка `"0"` или `"1"`, отделенная пробелом.  
* Кавычки («») вокруг текста допускаются, но не обязательны.

### Как работает сопоставление

**Английский текст:** Скрипт извлекает английские предложения из conll-файлов, используя номера предложений и флаги блоков.  
**Русский текст:** Русские предложения извлекаются из текстовых файлов, используя форматирование (номер предложения и метки `"0"`/`"1"`).  
**Сопоставление:**

* Для каждого номера предложения проверяется, совпадает ли количество строк в русском и английском текстах.  
* Если совпадает, строки сопоставляются построчно. Если нет, русский перевод для таких предложений остается пустым.

**Результат:** После сопоставления в итоговый датасет добавляется поле `"text_rus"`, содержащее русский перевод.
