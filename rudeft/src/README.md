# Скрипты

### Подготовка датасета
- `translator_connl_to_hf.py` - Конвертер CONNL формата оригинального DEFT к HF формату 
- `eng_ru_matching_pipeline.py` - Скрипт добавления к HF датасету с английским текстом имеющегося русского перевода

### Пайплайн обработки с помощью LLM
- `translation_via_llm.py` - Cкрипт взаимодействия с LLM для перевода предложений датасета на другой язык
- `markup_transfer.py` - Cкрипт взаимодействия с LLM для переноса разметки датасета

### Вспомогательные модули
- `batches_utils.py` - Модуль для реализации работы с батчами
- `stats_for_iob_transfer.py` - Скрипт для получения статистики по качеству переноса разметки датасета (например, на GOLD выборке)
